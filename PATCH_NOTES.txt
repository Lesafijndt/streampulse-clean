YEDI HUB — VERCEL FUNCTION CRASH HOTFIX

This is a two-file overlay for the existing project. It does not replace your UI, queue/player, OAuth login URL, CSS, or environment variables.

Files:
- api/twitch/session.js
  Firebase Admin is loaded only when creating an optional Firebase custom token. A missing/broken Firebase Admin package no longer prevents the Twitch session endpoint from starting or returning safe authentication diagnostics. If Firebase Admin cannot load, Twitch auth can still succeed but cloud token creation will be unavailable until the dependency is fixed.
- api/twitch/callback.js
  Passes req into clearAuthCookies in the catch path, preventing a secondary crash if the Twitch token exchange hits a network exception.

Install:
1. Extract this ZIP into the root of your existing GitHub repository and merge/replace the two matching files only.
2. Commit and push with GitHub Desktop.
3. Wait until the Vercel deployment finishes.
4. Open https://streampulse-clean.vercel.app/api/twitch/session again.

Expected when signed out: HTTP 200 JSON with authenticated:false and an authDiagnostic field. If the endpoint still returns 500 FUNCTION_INVOCATION_FAILED, open Vercel Dashboard > project > Logs / Functions and copy the first error line for /api/twitch/session, redacting credentials and tokens. The diagnostic JSON never returns secrets.
