Yedi Hub GACHI ARENA — START HERE
========================

This archive is the COMPLETE project. The repository root must be the folder
that contains BOTH index.html and the src folder.

REQUIRED STRUCTURE
------------------
index.html
package.json
vite.config.ts
vercel.json
src/App.tsx
src/main.tsx
src/index.css
src/vite-env.d.ts
api/resolve-tiktok.js
api/media-metadata.js

IMPORTANT: Do not upload the ZIP itself. Do not put the files inside an extra
nested folder in GitHub. In particular, the final path must be:
  src/main.tsx
NOT:
  Yedi Hub/src/main.tsx
  src/src/main.tsx

The api/ folder is needed to resolve TikTok short share links after deployment.

CREATE A CLEAN GITHUB REPOSITORY
--------------------------------
1. On GitHub.com, create a NEW empty repository (for example,
   yedi-hub-gachi). Leave “Add a README”, .gitignore, and license unchecked.
2. In GitHub Desktop, choose File > Clone Repository, select the new repository,
   and clone it to your computer.
3. In GitHub Desktop choose Repository > Show in Explorer.
4. Copy EVERYTHING from the extracted Yedi Hub Gachi Arena project folder into the
   cloned repository folder. Copy the contents, including the src folder—not
   the outer project folder and not the ZIP. Keep the hidden .git folder in the
   cloned repository.
5. In GitHub Desktop, open Changes. You should see index.html, package.json,
   src/App.tsx, src/main.tsx and the other files.
6. Commit to main, then click Push origin.
7. Open the new GitHub repository on the website. The src folder must appear
   at the top level. Open src/main.tsx to make sure it is visible (not 404).

DEPLOY ON VERCEL
----------------
1. In Vercel, choose Add New > Project and import the NEW GitHub repository.
2. Framework preset: Vite
3. Root directory: leave at repository root (usually shown as .).
4. Build command: npm run build
5. Output directory: dist
6. Click Deploy.

The chat transcript is intentionally removed; the Twitch IRC bridge connects automatically on page load, retries disconnections, and only handles commands. Channel settings sync per room when Firebase is configured.

If you use Firebase cloud sync, follow the optional instructions in README.md and publish firestore.rules, including the room_settings match.
The app can run in browser-local mode without Firebase environment variables.

CHANNEL LINKS
-------------
A room can be opened on any device by adding ?channel=TWITCH_LOGIN to the deployed URL, e.g. https://your-site.vercel.app/?channel=example. It will load cloud queue/settings and auto-connect its bridge while the page is open.
