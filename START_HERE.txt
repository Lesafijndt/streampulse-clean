YEDI HUB — PRIVATE TWITCH REQUEST DECK
======================================

This bundle is dedicated to channel twitch.tv/2o3a. The only allowed website
accounts are:
  • 2o3a — streamer permissions
  • paim_beach_pete — moderator permissions
Every other Twitch account is denied by the server. Roles cannot be chosen in
the browser. Firestore rules also reject anonymous/public Firebase sessions.

SET UP TWITCH OAUTH
-------------------
1. Visit https://dev.twitch.tv/console/apps and register an application.
2. OAuth Redirect URL must be exactly:
   https://streampulse-clean.vercel.app/api/twitch/callback
   If the Vercel project uses another domain, replace this URL with that domain.
3. In Vercel → Project → Settings → Environment Variables, add (Production and
   Preview as appropriate):
   TWITCH_CLIENT_ID       = the Twitch app Client ID
   TWITCH_CLIENT_SECRET   = the Twitch app Client Secret
   TWITCH_APP_URL         = https://streampulse-clean.vercel.app
   TWITCH_REDIRECT_URI    = https://streampulse-clean.vercel.app/api/twitch/callback
4. Redeploy after adding them.

SECURE FIREBASE SYNC (RECOMMENDED FOR CROSS-DEVICE QUEUE)
--------------------------------------------------------
The site works with browser-local storage if Firebase is not configured, but
that queue will not sync across browsers. For private cloud sync:

1. Configure the six VITE_FIREBASE_* browser config values in Vercel as before.
2. In Firebase Console → Project settings → Service accounts, generate a private
   key for the Firebase Admin SDK. Keep that downloaded JSON private.
3. Add this Vercel server-only environment variable:
   FIREBASE_SERVICE_ACCOUNT_JSON = the FULL contents of the service-account JSON
   Do not prefix it with VITE_, do not put it in GitHub, and do not share it.
4. In Firebase Console → Authentication → Sign-in method, enable Custom auth if
   your project asks for it, and in Firestore → Rules publish the supplied
   firestore.rules. Do not keep the old permissive anonymous-access rules.
5. Redeploy Vercel.

The server uses Firebase Admin only to mint short-lived custom sign-in tokens for
the two allowlisted Twitch identities. The browser never receives the service
account private key. Firestore reads/writes require the yediAuthorized custom
claim plus an approved Twitch login and role.

DEPLOY WITH GITHUB DESKTOP
--------------------------
1. Extract this ZIP.
2. Open the existing repository in GitHub Desktop → Repository → Show in Explorer.
3. Copy the extracted project CONTENTS (including the src and api folders) into
   that repository folder, overwriting files when prompted. Do not remove .git.
4. In GitHub Desktop, commit to main, then click Push origin.
5. In Vercel, redeploy the project and check Build Logs.
6. Set Framework preset Vite, Build command npm run build, Output directory dist.

BEHAVIOR / LIMITS
-----------------
• The room is permanently fixed to twitch.tv/2o3a; URL parameters cannot switch it.
• The hidden Twitch IRC bridge joins only after one of the approved Twitch users
  has logged in. It reads new chat requests while this page/OBS browser source is
  open; the Vercel website does not run a 24/7 IRC connection after all browsers close.
• `!assr <URL>` is the chat request command. The site does not display a chat transcript.
• Audible autoplay can still be blocked by a browser until Play is clicked once.
• OAuth cookies are HttpOnly, Secure in production, and SameSite=Lax. Logging out
  clears the Twitch cookies and Firebase client session.
