YEDI HUB PATCH — BLACK-SCREEN CONTAINMENT, !HELP, CINEMA PLAYER

Changes:
- Added !help command with viewer commands and moderator/broadcaster commands in three short Twitch chat messages.
- Removed fullscreen permission and allowFullScreen from the TikTok iframe. This is a targeted mitigation because the reported symptom is the entire page going black after Next Track, not just the embedded video. The TikTok player no longer has permission to take over the page's fullscreen surface.
- Increased the player viewport to cinema-sized responsive heights. Theatre mode uses 72vh (560–900px); normal mode uses 55vh (460–700px).
- Added explicit stacking/isolation to the TikTok iframe so its rendering surface stays inside the player viewport.

Commands in !help:
- Viewers: !assr <URL>, !position / !queue / !when, !bigcock [queue position]
- Staff: !skip and volume/mute commands.
- Queue position and wait times are estimates; votes can change queue order.

Install:
1. Extract/merge this ZIP into the existing project root.
2. Commit and Push origin in GitHub Desktop.
3. Wait for Vercel deployment and test !help and Next Track into multiple TikToks.

Validation note:
The ZIP was created from the current project source. A production build could not be run because dependencies (Vite) are not installed in this environment. This is a targeted mitigation, not a guarantee against TikTok-side embed failures. If the entire page still goes black, please capture the browser console error (F12 > Console) after the skip; that would point to a separate runtime error or browser-level failure.
