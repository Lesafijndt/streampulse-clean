Yedi Hub — !bigcock chat command update

WHAT CHANGED
- Replaces the Twitch chat upvote command !hype with !bigcock.
- The command still upvotes the currently playing video/request.
- The old !hype command is no longer recognized.
- Keeps the latest TikTok autoplay behavior from the provided project patch.

INSTALL
1. Extract this ZIP into the ROOT of your local Yedi Hub repository (the folder containing package.json).
2. Allow it to replace src/App.tsx.
3. In GitHub Desktop, review the changed file, commit, and Push origin.
4. Wait for Vercel to deploy, then test by typing !bigcock in 2o3a's Twitch chat while a video is playing.

NOTE
This ZIP contains only src/App.tsx plus these instructions; it is a targeted source patch, not the full project. A full production build was not run in this environment.
